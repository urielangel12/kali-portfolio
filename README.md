## 🛠️ Sobre este proyecto

Portafolio construido con:
- **React 19 + Vite** — interfaz rápida y moderna
- **Tailwind CSS** — diseño responsive con tema personalizado inspirado en Kali Linux
- **react-i18next** — contenido 100% bilingüe (Español / English)
- **Framer Motion** — animaciones fluidas
- **Lucide React** — iconografía

### Características
- Diseño responsive (móvil, tablet, escritorio)
- Cambio de idioma en tiempo real (ES/EN)
- Secciones: Sobre mí, Arsenal de ciberseguridad, Experiencia, Proyectos, Labs, Certificaciones, Contacto
- Formulario de contacto integrado con Gmail

### Correr el proyecto localmente
```bash
npm install
npm run dev
```
